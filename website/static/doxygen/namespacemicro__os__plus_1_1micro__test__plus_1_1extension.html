Detailed Description

The extension namespace holds what the applications use to write their own comparators, predicates, operators, and helpers, reported as the built-in ones are:

  • compare_op and predicate_op (declared in detail.h), the expressions of the binary comparisons and of the unary predicates, parametrised by a tag that defines the operation and its symbol in the failure reports;
  • the C++20 concepts with the same constraints as the framework itself: whether a type is a framework expression or value wrapper (is_op, any_op), whether it carries a floating-point tolerance (has_epsilon), and whether it is accepted by expect() and require() (checkable) or by the message operator (printable).

The namespace is separate from the top namespace, so that using namespace micro_os_plus::micro_test_plus does not bring these generic names into the application code; refer to them qualified, as mt::extension::is_op<T>.
