Detailed Description

The name parameter of suite::test(), test_case::test(), test_each(), runner::add_suite(), runner::add_top_suite(), and the static_suite constructors. The constructors are not explicit, so a string literal, a const char*, a std::string, or a std::string_view passed as the name converts implicitly; the default argument of the constructors is evaluated at the place of the conversion, which is the call in the user code, so the location is captured without an additional argument (which could not follow the variadic arguments of these functions).

The name is copied, so the argument need not outlive the call, and a std::string_view need not be null-terminated; a temporary std::string is moved. The copy of a test case name lives until the end of the call to test(), within which the test case runs, so the memory used does not grow with the number of test cases; the suites, which run later, keep their name, moved, until they are destroyed.

The location of a test case is used to report a failure that is not associated with a check, such as an exception escaping the test case body; the suites keep their location, but do not report it.

Since a conversion sequence may include only one user-defined conversion, an argument that converts to const char*, to std::string, or to std::string_view via a user-defined conversion operator must be converted explicitly.

A helper function that adds test cases on behalf of its caller can take a const located_name& parameter and pass it to test(), so that the reported location is that of the call to the helper, not that of the call to test() inside the helper.

Example
namespace mt = micro_os_plus::micro_test_plus;
void
check_answer (mt::suite& ts, const mt::located_name& name, int v)
{
ts.test (name, [v] (auto& t) { t.expect (mt::eq (v, 42)); });
}
