Detailed Description

Template Parameters
TThe type to be checked.

The is_op concept is satisfied when T has the op_type member type alias of detail::op, either inherited from the detail::op base struct, or declared directly, like in detail::value_base, which avoids the empty base. It is used throughout the framework, both as a constraint and as a boolean expression in if constexpr contexts.

A custom comparator or operator uses it to tell the framework operands, like to_i or the _i literals, from the types of the application. The applications build their own expressions with extension::compare_op and extension::predicate_op, not by declaring the op_type marker, which the formatter could not report.
