Template Parameters
TThe signed integral type of the literal.

The absolute value of the minimum of a signed type (e.g. 128 for int8_t) does not fit in the type, but the literal must be accepted to write the minimum with the unary minus (e.g. -128_i8). The literal operators return this type for such a literal; its only operation is the unary minus, so any other use of the literal fails to compile.
