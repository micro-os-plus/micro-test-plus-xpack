 Appends a value to a text, in the plain mode of the formatter.

Detailed Description

Gives access to the plain mode of the expression_formatter, which is private, so that the names of the test cases generated by test_each() show their values as the messages do: the numbers without the type suffixes, and the characters unquoted.
