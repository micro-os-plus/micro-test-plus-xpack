Detailed Description

This header provides the inline and template implementations for the test hierarchy used within the µTest++ framework: the accessors of the base classes, the constructors that bind the callable objects and their arguments, the test() member functions that create and run test cases, and the expect() and require() checks.

When additional arguments are given, a detail::bound_callable holds copies of the callable and of the arguments. The suites store this object in a std::function, while the test cases only refer to it, through a detail::callable_ref, as a local object of the test() call that runs them. A static_suite additionally inserts itself into the list of suites upon construction.

All definitions reside within the micro_os_plus::micro_test_plus namespace, maintaining a clear separation from user code and minimising the risk of naming conflicts.

The header files are organised within the include/micro-os-plus/micro-test-plus folder to maintain a structured and modular codebase.

This file is intended solely for internal use within the framework and should not be included directly by user code.
