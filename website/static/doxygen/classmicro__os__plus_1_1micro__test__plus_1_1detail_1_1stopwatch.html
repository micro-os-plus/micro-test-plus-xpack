Detailed Description

start() reads the system clock just before the measured operation and stop() just after it; when both readings are available, elapsed() returns the interval between them.

Each call reads the clock again: start() restarts the measurement, discarding both previous readings, and stop() replaces the previous stop reading, if any. A zero reading means that the clock was not read, either because the stopwatch was not started (or stopped), or because the platform has no clock; in both cases has_elapsed() returns false, so that the reporters can skip the timing output.

Typical usage in the framework:

  1. Call start() just before the test suite or session body executes.
  2. Call stop() immediately after it completes.
  3. The reporters display elapsed(), when has_elapsed().

The class is non-copyable and non-movable to prevent accidental sharing of live timing state.

The class is final; the non-public members are private, and only the unit tests, through a friend, set known readings.

The public members of the v5.0.1 detail::timestamps class (timestamp_begin(), timestamp_end(), has_begin(), has_end(), has_timestamps(), and compute_elapsed_time()) are kept, deprecated, for the applications that used the deprecated timings() of the runner and of the suites, which return a reference to this class.
