Detailed Description

Template Parameters
Lhs_TThe type of the left-hand operand.
Rhs_TThe type of the right-hand operand.

The any_op concept is satisfied when Lhs_T or Rhs_T (or both) are framework expression types (see is_op). It is used to constrain binary operator overloads in the operators namespace so that they are enabled only when at least one operand is a framework type, avoiding unintended conflicts with user-defined operators.

A custom operator uses it in the same way, so that it does not compete with the operators of the application types.
