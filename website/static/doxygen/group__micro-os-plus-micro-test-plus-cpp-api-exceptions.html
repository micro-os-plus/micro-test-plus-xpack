Detailed Description

Dedicated exception-check utilities verify whether expressions or function calls throw. These utilities support robust testing of error handling and exceptional conditions in C++ code.

Developers can assert that exceptions are thrown, or not thrown, as expected, improving the reliability and safety of software components. The framework supports both generic checks and type-specific verification, allowing precise and expressive test cases.

When such a check fails, the report states why: for example throws<std::runtime_error>, but nothing was thrown, throws<std::runtime_error>, but a std::exception was thrown: "what" (with the text returned by its what()), or nothrow, but an exception of unknown type was thrown.

A failed require() inside the callable is not an exception of the callable: it stops the test case, as it does elsewhere, and does not satisfy throws() or fail nothrow().

For advanced scenarios, such as handling multiple expected exception types, use explicit try blocks with multiple catch statements and report results with expect(true) or expect(false). This approach enables comprehensive coverage of exception-handling logic.

Examples
ts.test ("Check if exceptions are thrown", [] (auto& t) {
t.expect (mt::throws ([] { exercise_throw (true); }))
<< "exception thrown";
t.expect (mt::throws<std::runtime_error> ([]
{ throw std::runtime_error{ "" }; }))
<< "std::runtime_error thrown";
t.expect (mt::nothrow ([] { exercise_throw (false); }))
<< "exception not thrown";
});
ts.test ("Check exceptions explicitly", [] (auto& t) {
try
{
compute_answer ();
}
catch (const std::overflow_error& e)
{
t.expect (true) << "std::overflow_error thrown";
}
catch (const std::runtime_error& e)
{
t.expect (true) << "std::runtime_error thrown";
}
catch (...)
{
t.expect (false) << "unknown exception thrown";
}
});

The nothrow function template verifies whether invoking the provided callable object does not result in the throwing of any exception within the µTest++ framework. This is useful for ensuring that code under test does not unexpectedly signal error conditions.

The callable is invoked immediately, when the comparator is constructed; the result is reported when the comparator is passed to expect() or require(), which also accept optional messages.

template<class Exception_T, class Callable_T>
auto micro_os_plus::micro_test_plus::throws ( const Callable_T & func)
nodiscard

The callable is invoked once, immediately. The check passes if it throws an exception of type Exception_T or of a type derived from it, so throws<std::exception>() passes for any standard exception. An exception of another type, or no exception, fails the check, and the report states what was thrown.

Template Parameters
Exception_TThe type of the exception expected to be thrown.
Callable_TThe type of the callable object to be invoked.
Parameters
funcThe callable object to check for exception throwing behaviour.
Returns
An object of an unspecified type, holding the result, to be passed to expect() or require().

The throws function template verifies whether invoking the provided callable object results in the throwing of a specific exception type within the µTest++ framework. This is useful for testing error handling in code under test. Exceptions of other types are reported as failures.

The callable is invoked immediately, when the comparator is constructed; the result is reported when the comparator is passed to expect() or require(), which also accept optional messages.
