Type Wrappers

Strongly-typed wrappers for converting dynamic values and expressions to specific types recognised by µTest++ comparators.

These type aliases provide a type-safe mechanism for explicitly converting values to the required types for µTest++ test expressions and comparators. Each alias is a wrapper around detail::value<T>, ensuring that the value is treated as the specified type within the framework.

The to_* forms replaced the older _i, _u8, etc. aliases, which were deprecated in version 3.2.0.

Deprecated
Pass the plain values to the function comparators eq(), ne(), gt(), ge(), lt(), and le() instead; they report the operands in the same way. For the floating-point values compared with a tolerance, use approx() (since 5.1.0).
Example
int x = 42;
// Explicitly treat x as an int for test comparison.
auto wrapped = to_i{x};

Deprecated Type Wrappers

The v5.0.1 names of the to_* type wrappers.

The Boost UT style names, with a leading underscore, kept for compatibility with the existing applications. Each one is an alias of the corresponding to_* wrapper, so the wrapped values are compared and reported in the same way. They do not conflict with the literal operators with the same suffixes (42_i), which are in the literals namespace.

GCC reports the deprecation only when the alias names the type of a declaration, not when it is used in an expression, as in _i (expr); Clang reports it in both cases.

Deprecated
Pass the plain values to the function comparators eq(), ne(), gt(), ge(), lt(), and le() instead; the to_* type wrappers that replaced these aliases (since 3.2.0) are deprecated too (since 5.1.0).

Detailed Description

This header groups the deprecated definitions that are not members of the framework classes, kept for compatibility with the applications written for the previous versions:

  • the v5.0.1 names of the logical functions (_not, _and, and _or);
  • the overloaded operators of the operators namespace, the user-defined literals of the literals namespace, the to_* type wrappers, to_t<T>, and approx (value, epsilon), deprecated since 5.1.0 in favour of the function comparators;
  • the v5.0.1 names of the type wrappers (_i, _u8, etc.);
  • the v5.0.1 names of the classes (subtest, static_runner, detail::runner_totals, and detail::timestamps);
  • the detail::timestamp class;
  • the reflection::short_name() function;
  • the v5.0.1 type_traits namespace.

The deprecated member functions and data members remain in the declarations of their classes, since C++ does not allow them to be declared elsewhere.

Keeping the deprecated definitions separate makes them easy to identify and, in a future major release, to remove.

All definitions reside within the micro_os_plus::micro_test_plus namespace, ensuring clear separation from user code and minimising the risk of naming conflicts.

The header files are organised within the include/micro-os-plus/micro-test-plus folder to maintain a structured and modular codebase.

This file is intended for internal use within the framework and should not be included directly by user code.
