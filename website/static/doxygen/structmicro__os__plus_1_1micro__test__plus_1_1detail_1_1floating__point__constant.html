Detailed Description

template<class T, auto N, auto D, auto Size, auto P = 1>
struct micro_os_plus::micro_test_plus::detail::floating_point_constant< T, N, D, Size, P >
Template Parameters
TThe floating point type (e.g., float, double).
NThe integral part of the constant value.
DThe digits of the fractional part of the constant value, as returned by math::den() (e.g. 25 for 1.25).
SizeThe number of decimal digits, the scale of D, as returned by math::den_size() (e.g. 2 for 1.25).
PThe sign of the value (1 for positive, -1 for negative). Defaults to 1.

The floating_point_constant struct template provides a compile-time constant value of a floating point type, supporting custom size and precision. It inherits from op directly rather than from value_base<T>, since its value is the compile-time value constant, and it needs no run-time storage; the struct is empty, and the literal operators create it with {}, without a constructor. Having no non-static floating point members, it is not a homogeneous floating point aggregate, so the -Wpsabi note described for value_base does not apply to it, despite its empty base. On 32-bit Arm, GCC emits another note, about a change in GCC 7.1, for each function passing a double or long double constant by value, since the earlier versions computed its alignment from its static double members; the framework does not pass the constants by value.

The value_type alias, explicit conversion operator, and get() accessor are provided directly by this struct. The compile-time epsilon and value static constants are retained, and a unary minus operator is provided to obtain the negative value as a new floating_point_constant instance.
