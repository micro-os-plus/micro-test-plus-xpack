Detailed Description

This base struct provides common functionality for operators that wrap callable invocations, particularly for exception-checking operations. Derived structs (such as throws_op and nothrow_op) use this base to store and manage the pre-computed boolean result of a callable invocation, enabling consistent reporting and composition of exception-checking assertions.
