Detailed Description

expression_formatter owns a std::string buffer and provides operator<< overloads for all standard arithmetic types, character types, strings, pointers, containers, scoped enumerations (including std::byte), pairs, tuples, optionals, and framework expression types (see extension::is_op).

The numeric overloads append a type suffix named after the µTest++ literals (e.g., 42u, 3l, 5sc, 1.5f, 1.5ld); int and double have no suffix, and the floating-point values always have a decimal point or an exponent (42.0), so that they can be distinguished from the integers.

The same overloads also write the messages appended to the checks (expect (...) << value), so that a message accepts the same values as an expression, including the application types with an operator<< for this formatter. For the messages, check_result uses a formatter in the plain mode, which writes the numbers without the type suffixes and without the added decimal point (42, 1.5), and the char values unchanged, without quotes, as text; the other values are written as in the expressions.

The class is non-copyable and non-movable to avoid accidental copying of the internal buffer.

Apart from the constructor, the public members are the operator<< overloads and the read-only str(), so that the application operator<< functions for user-defined types can only append text. The functions that assign the buffer to a check, and return and release its text, are private, and called only by check_result, a friend; an application function calling them would corrupt the texts of the pending checks.

Shared by the overloads of all the character types, so that they escape the values in the same way. The usual escape sequences are used for '\\0', '\\a', '\\b', '\\t', '\\n', '\\v', '\\f', '\\r', '\\'', and '\\\\', and the other control characters and DEL are written as two hexadecimal digits ('\\x1b'). The values that are not characters by themselves (the values above 0x7F of the 8-bit types, the surrogates, and the values above 0x10FFFF) are written with \\x and all the hexadecimal digits of their type, and the other values outside ASCII as universal character names, \\u with four digits, or \\U with eight. The printable ASCII characters are written unchanged. The hexadecimal digits are lowercase.

Parameters
prefixThe prefix of the literal ("", "u8", "u", "U", or "L").
codeThe value, converted without the sign extension.
sizeThe size of the character type, in bytes.
Returns
Nothing.

A value of an 8-bit type above 0x7F is a part of a multi-byte sequence; for the wider types, the surrogates (0xD800 to 0xDFFF) and the values above 0x10FFFF are not Unicode characters, and cannot be written as universal character names. They are written with \\x and twice as many hexadecimal digits as the bytes of the type, so that the width of the type is visible. The control characters keep the two digits of char, since they are the same in all the encodings.
