Detailed Description

template<class T>
requires std::floating_point<T>
struct micro_os_plus::micro_test_plus::detail::value< T >
Template Parameters
TThe floating point type to be encapsulated.

The value struct template specialisation for floating point types encapsulates a value of type T and provides an associated epsilon for precision control during comparisons. The stored value, explicit conversion operator, and getter are provided by the value_base base.

The epsilon member defines the precision used for floating point comparisons and can be set explicitly (by approx()) or computed as a default based on the number of decimal digits in the value (by the to_f, to_d, and to_ld wrappers).

template<class T>
T micro_os_plus::micro_test_plus::detail::value< T >::epsilon = T{}

This instance member defines the precision for comparisons. It is set via the constructor, either explicitly or computed as a default based on the number of decimal digits in the value. Each instance carries its own epsilon, so two value<T> objects with different precisions do not interfere with each other.
