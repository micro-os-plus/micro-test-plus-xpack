Detailed Description

The types that satisfy extension::printable but not this concept are the application types, written by a free operator<< found by argument-dependent lookup. A type may satisfy both, if it is accepted by a template of the formatter (a scoped enumeration, or a type with begin() and end()) and the application also defines an operator<< for it; see free_printable.
