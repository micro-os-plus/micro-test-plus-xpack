Detailed Description

The v5.0.1 class of the two readings kept by detail::timestamps, restored for the applications that used it directly; the framework no longer uses it, since stopwatch keeps the readings as timespec members. The timings are internal; use stopwatch instead.

A zero timespec means that the clock was not read, or that the platform has no clock.

The data member is protected, as in v5.0.1, so that the existing derived classes can still access it.

Deprecated
the timings are internal (since 6.0.0)
