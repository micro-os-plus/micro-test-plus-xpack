Detailed Description

template<auto N>
struct micro_os_plus::micro_test_plus::type_traits::integral_constant< N >
Template Parameters
NThe compile-time constant value.

The integral_constant struct template provides a compile-time constant value of an integral type, created by the integer literals. It inherits from value_base<decltype(N)>, which supplies the value_type alias, the runtime value storage, the explicit conversion operator, and the get() accessor.

This struct retains the compile-time value constant and provides a unary minus operator to obtain the negative value as a new integral_constant instance, of the same type.

◆ operator-()

template<auto N>
auto micro_os_plus::micro_test_plus::detail::integral_constant< N >::operator- ( ) const
nodiscardconstexprnoexcept

The result has the type of N, not the type promoted by the built-in unary minus, so -1_i8 is an int8_t. The negation of an unsigned value wraps around, as for unsigned int in C++ (-1_u8 is 255). The negation of the minimum of a signed type does not fit in the type, so it is a compilation error.

Returns
An integral_constant with value -N, converted to the type of N.

The built-in unary minus promotes the types narrower than int, so its result is converted back to the type of N. For the unsigned types, the value is subtracted from zero, which, after the conversion, gives the value modulo 2^n for all widths. For the signed types, the minimum is rejected before the negation, which would otherwise overflow for int and the wider types.
