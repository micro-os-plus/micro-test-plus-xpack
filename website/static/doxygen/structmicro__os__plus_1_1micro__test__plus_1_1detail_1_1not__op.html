Detailed Description

template<class T>
struct micro_os_plus::micro_test_plus::detail::not_op< T >

Derived from unary_op, this struct negates a single sub-expression, enabling test writers to assert that a condition does not hold. The negation result is computed at construction time, ensuring consistent reporting throughout the assertion framework.

The sub-expression is not copied: a temporary is moved into the comparator, and a named one is referred to (see stored_operand_t).

There is no deduction guide: with a single argument that is itself a not_op, the class template argument deduction prefers the copy deduction candidate, so not_op{ inner } would copy inner instead of negating it. Name the template argument instead, as not_op<stored_operand_t<T>>{ t }.

Template Parameters
TThe type of the stored sub-expression, either its type, or a const reference to it.
