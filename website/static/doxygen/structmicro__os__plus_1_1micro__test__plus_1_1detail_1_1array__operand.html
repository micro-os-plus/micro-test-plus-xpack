Detailed Description

template<class T>
struct micro_os_plus::micro_test_plus::detail::array_operand< T >

The comparators convert the arrays of any element type except char (the byte buffers, the arrays of numbers, and the arrays of the wide character types) to this type (see as_operand()), so that they are compared element by element, and written as ranges, instead of being compared and written as the addresses they decay to. Two arrays of different sizes are never equal.

The elements are not copied; the operand must outlive the comparison, which is always the case within a check.
