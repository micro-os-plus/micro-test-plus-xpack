Detailed Description

This header provides the out-of-line template and inline implementations for all types declared in detail.h. It defines the bodies of the unwrap() helper, the unary and binary operator base class templates, the comparison tags, all relational, approximate, and logical comparator constructors, the predicate constructor, the tolerance helpers (within_tolerance(), differ_by_at_most()), the callable operator types (throws_op, nothrow_op), the append_number() and append_pointer() formatting helpers, the basic_c_string operand and its operators, and as_operand().

Separating the implementations from the declarations keeps detail.h concise and focused on the interface, whilst grouping the complex lambda-based constructor bodies here for maintainability.

All definitions reside within the micro_os_plus::micro_test_plus::detail namespace.

This file is included by detail.h; the applications include micro-os-plus/micro-test-plus.h, not this file.
