Detailed Description

This header provides the runner_options structure, which holds the configuration of a test session (the reporter, the verbosity, the output file, the use of colours, the filter, and the listing of the test cases), together with the reporter_kind, verbosity, and colour_mode enumerations used by its members.

The options are usually parsed from the command line by runner::initialise (argc, argv); the applications without a command line, such as the embedded ones without semihosting arguments, can set them directly and pass them to runner::initialise (options).

All definitions reside within the micro_os_plus::micro_test_plus namespace, ensuring clear separation from user code and minimising the risk of naming conflicts.

The header is included through micro-test-plus.h and should not be included directly by user code.
