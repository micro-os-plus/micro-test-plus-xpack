Detailed Description

This header provides the C++20 concepts that the applications use to extend the framework with their own comparators, operators, and helpers (the expressions they return, extension::compare_op and extension::predicate_op, are declared in detail.h): the concepts that detect the framework expressions and value wrappers, their floating-point tolerance, and the types accepted by expect(), require(), and the message operator.

The public concepts reside within the micro_os_plus::micro_test_plus::extension namespace, separate from the top namespace, so that using namespace on the top namespace does not bring their generic names into the application code.

The concepts used only by the implementation, which detect the framework constants, the containers, and the strings, reside within the detail namespace.

The value wrappers themselves are declared in values.h, in the detail namespace.

The deprecated v5.0.1 type_traits namespace, which refers to these concepts and to the value wrappers, is also declared here.

All header files are organised within the include/micro-os-plus/micro-test-plus folder to maintain a structured and modular codebase.

This file is intended for internal use within the framework and should not be included directly by user code.
