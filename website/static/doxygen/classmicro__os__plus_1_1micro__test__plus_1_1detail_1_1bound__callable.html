Detailed Description

template<typename Self_T, typename Callable_T, typename... Args_T>
class micro_os_plus::micro_test_plus::detail::bound_callable< Self_T, Callable_T, Args_T >

Returned by bind_callable() when there are additional arguments. When invoked with a Self_T& reference, it invokes the stored callable with that reference, followed by the stored arguments, as non-const lvalues.

It replaces a lambda, since the function call operator of a lambda cannot be marked as always inlined in a way accepted by all the supported compilers; without optimisations, a separate frame for it would make the call chain of each nested test case longer.

Template Parameters
Self_TThe type referred to by the first parameter of the callable (test_case or suite).
Callable_TThe type of the stored callable (decayed).
Args_TThe types of the stored arguments (decayed).

Constraints
At least one argument, so that the copy and move constructors are used for copies (there is always at least one stored argument, and the member initialisation requires one argument for each of them). The constraint does not refer to Args_T, since clang 17 and 18 crash on the out-of-line definition of a constraint that refers to the pack of the enclosing class.
Parameters
callableThe callable object.
argumentsThe arguments passed to the callable after the leading reference.

The callable and the arguments are forwarded to the constructors of the members, which store decayed copies.
