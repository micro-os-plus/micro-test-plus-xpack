Detailed Description

This struct checks whether invoking the given callable completes without throwing an exception. The check is performed at construction time, with the result cached for reporting and composition. Use this when a test must verify that an operation does not throw.

The callable is a parameter of the constructor only, so all the checks share one struct, and one formatter overload.
