Detailed Description

Template Parameters
TThe type to be checked.

The has_epsilon concept is satisfied when T is a framework expression type (see is_op) with an epsilon member, like floating_point_constant and the floating-point specialisation of value<T>. The comparators treat the operands within this tolerance as equal; a custom comparator uses it to do the same.

The types of the application are excluded, even if they have a member named epsilon, so that they are compared with their own operators.
