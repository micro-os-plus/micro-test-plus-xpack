759 // out-of-line in type-traits-inlines.h. Clang 16 has a deficiency
760 // where it fails to match out-of-line constructor definitions to a
761 // `requires`-constrained partial specialisation: it either rejects
762 // the `requires` clause on the definition as differing from the
763 // declaration, or — when the clause is omitted — incorrectly matches
764 // the definition against the primary template instead of this
765 // specialisation. Keeping the bodies here avoids both failure modes.
