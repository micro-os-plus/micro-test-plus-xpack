767 // out-of-line in type-traits-inlines.h. Clang 16 has a deficiency
768 // where it fails to match out-of-line constructor definitions to a
769 // `requires`-constrained partial specialisation: it either rejects
770 // the `requires` clause on the definition as differing from the
771 // declaration, or — when the clause is omitted — incorrectly matches
772 // the definition against the primary template instead of this
773 // specialisation. Keeping the bodies here avoids both failure modes.
