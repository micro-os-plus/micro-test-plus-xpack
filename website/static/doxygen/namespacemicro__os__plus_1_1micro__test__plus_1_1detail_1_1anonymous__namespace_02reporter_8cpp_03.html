Detailed Description

The unnamed namespace gives the helpers internal linkage, so that they are visible only in this translation unit, and cannot conflict with the names of the application or of the other source files of the framework. They are not declared in any header.

The namespace is opened twice in this file, each time before the code that uses its helpers; Doxygen merges the two parts. The first part contains write_without_colours(), which copies the console output to the output file. The second part contains the helpers of the totals lines: fragment_size, plural(), and format_skipped().

◆ write_without_colours()

void micro_os_plus::micro_test_plus::detail::anonymous_namespace{reporter.cpp}::write_without_colours ( FILE * file,
std::string_view text )

The text may contain ANSI colour sequences, added when the console is a terminal, which must not reach the file. They are removed while writing: each ESC [, followed by any digits and semicolons, and terminated by m, is skipped, and the text between the sequences is written unchanged. Any other use of ESC is written as is. No line ending is appended.

Parameters
fileThe file to write to; must not be null.
textThe text to write.
