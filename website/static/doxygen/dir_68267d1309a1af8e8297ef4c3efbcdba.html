Detailed Description

The src folder contains the .cpp implementation files for the µTest++ library. Each file provides the non-inline method definitions for one or more related components:

  • check-result.cpp — check_result construction and reporting
  • counters.cpp — counters accumulation and operator+=
  • expression-formatter.cpp — non-template operator<< overloads of the expression formatter, and the texts of the pending checks
  • runner-options.cpp — runner_options command line parsing, and the reporting of the option errors
  • reporter-human.cpp — human-readable reporter implementation
  • reporter-tap.cpp — TAP-format reporter implementation
  • reporter.cpp — base reporter class and operator<< overloads
  • runner.cpp — runner constructors, option parsing, suite registration, run_suites(), and abort()
  • stopwatch.cpp — stopwatch clock readings and elapsed-time computation
  • test.cpp — suite, top_suite, static_suite, and test_case lifecycle methods
  • utility.cpp — extract_file_name(), is_match(), and split() helpers
