Detailed Description

The deprecated definitions are kept so that the tests written for the earlier releases still compile; they will be removed in a future major release. The compiler reports each use, with a message that names the replacement and the version that deprecated it (most of them since 6.0.0).

Availability
The deprecated definitions exist only when the application defines the macro MICRO_OS_PLUS_MICRO_TEST_PLUS_DEPRECATED_ENABLED (see Configuration). Without it, the tests that still use them do not compile, which shows what remains to be migrated.
Migration
Build once with the macro defined and the deprecation warnings enabled, and rewrite each reported use as its message suggests. While migrating, the applications that build with -Werror can disable the warnings temporarily with -Wno-deprecated-declarations.
namespace mt = micro_os_plus::micro_test_plus;
// Deprecated.
using namespace mt::operators;
using namespace mt::literals;
t.expect (compute_answer () == 42_i) << "answer is 42";
// Replacement.
t.expect (mt::eq (compute_answer (), 42)) << "answer is 42";

Deprecated groups
Three groups of deprecated definitions have topics of their own:
  • the overloaded comparison and logical operators (see Operators), replaced by the function comparators and the logical functions;
  • the user-defined literals and the type wrappers (see Literals and Wrappers), replaced by the plain values passed to the function comparators;
  • the logical functions _and(), _or(), and _not() (see Logical Functions), replaced by all_of(), any_of(), and negate().
Other deprecated definitions
  • the v5.0.1 names of the classes: static_runner (replaced by runner), subtest (replaced by test_case), detail::runner_totals (replaced by counters), and detail::timestamps and detail::timestamp, which are internal and not replaced;
  • runner (const char*), replaced by runner() followed by add_top_suite() (since 4.1.0);
  • runner::initialise (argc, argv, top_suite_name), replaced by initialise (argc, argv) followed by add_top_suite();
  • runner::exit_code(), replaced by runner::run_suites();
  • runner::suite(), replaced by runner::add_suite();
  • runner::suites_count(), replaced by added_suites_count() or total_suites_count();
  • runner::verbosity(), and runner::reporter() with its verbosity() member, replaced by runner::verbosity_level();
  • runner::timings() and test_case::timings(), and the members of detail::stopwatch kept from the v5.0.1 timestamps, which are internal and not replaced;
  • the counters members successful_checks(), executed_subtests(), and was_successful(), replaced by passed_checks(), executed_test_cases(), and passed() (the deprecated mutators increment_successful_checks() and increment_executed_subtests() were removed, since the counters are updated only by the framework);
  • test_case::assume(), replaced by test_case::require();
  • the overloads of test_case::expect() and test_case::require() that accept an argument that is always true (a string literal or a function name), replaced by writing the condition;
  • the static_suite constructor whose callable takes a static_suite&, replaced by a callable taking a suite&;
  • reflection::short_name(), replaced by utility::extract_file_name();
  • the type_traits namespace, with the concepts and the value wrapper templates of v5.0.1, replaced by the extension namespace;
  • the traits of the type_traits namespace: function_traits and list, which are not replaced, and identity, replaced by std::type_identity.

◆ within_tolerance()

template<class Lhs_T, class Rhs_T>
requires (extension::has_epsilon<Lhs_T> or extension::has_epsilon<Rhs_T>)
bool micro_os_plus::micro_test_plus::detail::within_tolerance ( const Lhs_T & lhs,
const Rhs_T & rhs )
nodiscardconstexpr

Used by compare_op for all six tags, so that a value within the tolerance is equal, and neither less nor greater; at least one operand must have an epsilon member (a floating-point literal, a to_f, to_d, or to_ld wrapper, or approx()).

Used only by the deprecated floating-point wrappers, it is available only when MICRO_OS_PLUS_MICRO_TEST_PLUS_DEPRECATED_ENABLED is defined.

Deprecated
To be removed with the deprecated floating-point wrappers (since 6.0.0).
Template Parameters
Lhs_TThe type of the left-hand operand.
Rhs_TThe type of the right-hand operand.
Parameters
lhsThe left-hand operand.
rhsThe right-hand operand.
Return values
trueThe absolute difference is less than the tolerance (the smaller one, if both operands have one).
falseOtherwise.

The tolerance is the smaller epsilon of the two operands, if both have one, otherwise the epsilon of the operand that has one. The operands are equal when the absolute value of their difference is less than the tolerance.
