Detailed Description

The op struct is the common base of the comparators defined in detail.h, of floating_point_constant, and of named_bool. It provides the op_type marker, which the extension::is_op and extension::any_op concepts use to distinguish the framework types from the user types, so that expect(), require(), and the operators in the operators namespace accept them.

The types that must not have an empty base, like value_base, declare the op_type marker directly instead of deriving from op.
