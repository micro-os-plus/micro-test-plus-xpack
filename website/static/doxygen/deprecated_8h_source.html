1871 * encapsulated value is treated as the specified type within the framework,
1872 * for the types without a `to_*` alias, including the application types;
1873 * with the operators of the `operators` namespace, the comparisons are
1874 * then reported with their operands.
1875 *
1876 * @par Example
1877 *
1878 * @code
1879 * namespace mt = micro_os_plus::micro_test_plus;
1880 *
1881 * MyType obj;
1882 * // Explicitly treat obj as MyType for test comparison.
1883 * auto wrapped = mt::to_t<MyType>{obj};
1884 * @endcode
1885 *
1886 * @par Replacement
1887 * Pass the plain value to the function comparators `eq()`, `ne()`,
1888 * `gt()`, `ge()`, `lt()`, and `le()` instead; the application types
1889 * are reported with the `operator<<` of `expression_formatter`.
1890 *
1891 * @headerfile micro-test-plus.h "micro-os-plus/micro-test-plus.h"
1892 */
1893 template <class T>
1894 struct [[deprecated (
1895 "pass plain values to eq() and the other comparators (since 6.0.0)")]]
