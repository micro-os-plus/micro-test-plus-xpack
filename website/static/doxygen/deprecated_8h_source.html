1874 * This wrapper inherits from `detail::value<T>`, ensuring that the
1875 * encapsulated value is treated as the specified type within the framework,
1876 * for the types without a `to_*` alias, including the application types;
1877 * with the operators of the `operators` namespace, the comparisons are
1878 * then reported with their operands.
1879 *
1880 * **Example**
1881 *
1882 * @code
1883 * MyType obj;
1884 * // Explicitly treat obj as MyType for test comparison.
1885 * auto wrapped = to_t<MyType>{obj};
1886 * @endcode
1887 *
1888 * @par Deprecated
1889 * Pass the plain value to the function comparators `eq()`, `ne()`,
1890 * `gt()`, `ge()`, `lt()`, and `le()` instead; the application types
1891 * are reported with the `operator<<` of `expression_formatter`
1892 * (since 6.0.0).
1893 *
1894 * @headerfile micro-test-plus.h "micro-os-plus/micro-test-plus.h"
1895 */

1897 struct [[deprecated (
1898 "pass plain values to eq() and the other comparators (since 6.0.0)")]]
