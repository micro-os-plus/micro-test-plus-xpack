1869 * This wrapper inherits from `detail::value<T>`, ensuring that the
1870 * encapsulated value is treated as the specified type within the framework,
1871 * for the types without a `to_*` alias, including the application types;
1872 * with the operators of the `operators` namespace, the comparisons are
1873 * then reported with their operands.
1874 *
1875 * @par Example
1876 *
1877 * @code
1878 * MyType obj;
1879 * // Explicitly treat obj as MyType for test comparison.
1880 * auto wrapped = to_t<MyType>{obj};
1881 * @endcode
1882 *
1883 * @par Deprecated
1884 * Pass the plain value to the function comparators `eq()`, `ne()`,
1885 * `gt()`, `ge()`, `lt()`, and `le()` instead; the application types
1886 * are reported with the `operator<<` of `expression_formatter`
1887 * (since 6.0.0).
1888 *
1889 * @headerfile micro-test-plus.h "micro-os-plus/micro-test-plus.h"
1890 */
