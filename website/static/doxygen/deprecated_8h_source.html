1884 * This wrapper inherits from `detail::value<T>`, ensuring that the
1885 * encapsulated value is treated as the specified type within the framework,
1886 * for the types without a `to_*` alias, including the application types;
1887 * with the operators of the `operators` namespace, the comparisons are
1888 * then reported with their operands.
1889 *
1890 * **Example**
1891 *
1892 * @code
1893 * MyType obj;
1894 * // Explicitly treat obj as MyType for test comparison.
1895 * auto wrapped = to_t<MyType>{obj};
1896 * @endcode
1897 *
1898 * @par Deprecated
1899 * Pass the plain value to the function comparators `eq()`, `ne()`,
1900 * `gt()`, `ge()`, `lt()`, and `le()` instead; the application types
1901 * are reported with the `operator<<` of `expression_formatter`
1902 * (since 6.0.0).
1903 *
1904 * @headerfile micro-test-plus.h "micro-os-plus/micro-test-plus.h"
1905 */
