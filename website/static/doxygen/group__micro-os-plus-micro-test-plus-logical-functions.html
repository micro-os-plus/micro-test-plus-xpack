Detailed Description

The functions mt::both(), mt::either(), and mt::negate() combine multiple conditions, allowing expressive and concise test logic. mt::either() is an inclusive or: it is true also when both conditions are true.

The functions have descriptive names, since and, or, and not are alternative tokens and cannot be used as identifiers. Using these logical functions allows developers to express compound conditions clearly and improve readability.

Example
ts.test ("Check compound conditions", [] (auto& t) {
t.expect (mt::both (mt::eq (compute_answer (), 42),
mt::eq (compute_float (), 42.0)));
});

When operands are function comparators, use the overloaded logical operators &&, ||, and ! provided in the micro_test_plus::operators namespace for more natural logical expressions.

It is the function form of the && operator from the micro_test_plus::operators namespace.

The either function template provides a generic logical disjunction for any expression types. It constructs a detail::or_op logical disjunction object, which evaluates to true if at least one of the operands is true.

It is the function form of the || operator from the micro_test_plus::operators namespace; the disjunction is inclusive, so the result is also true when both conditions are true.

An object that evaluates to true if the operand is false.

The negate function template provides a generic logical negation for any expression type. It constructs a detail::not_op logical negator object, which evaluates to true if the operand is false; the template argument is named, since the class template argument deduction would copy an operand that is itself a not_op, instead of negating it.

It is the function form of the ! operator from the micro_test_plus::operators namespace.
