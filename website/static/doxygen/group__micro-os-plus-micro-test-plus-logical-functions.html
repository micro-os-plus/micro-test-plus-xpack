Detailed Description

The functions mt::all_of(), mt::any_of(), and mt::negate() combine multiple conditions, allowing expressive and concise test logic. mt::all_of() and mt::any_of() take two or more operands, and mt::any_of() is an inclusive or: it is true also when all the conditions are true. A chain of the same operation is reported as a single group, for example (a and b and c).

All the operands are evaluated before the check, so the functions do not stop at the first operand that decides the result, like the standard algorithms of the same names. After a using namespace std, an unqualified call with three or more operands of the same type selects the standard algorithm; call the functions as mt::all_of() and mt::any_of().

The functions have descriptive names, since and, or, and not are alternative tokens and cannot be used as identifiers. Using these logical functions allows developers to express compound conditions clearly and improve readability.

Example
ts.test ("Check compound conditions", [] (auto& t) {
t.expect (mt::all_of (mt::eq (compute_answer (), 42),
mt::eq (compute_float (), 42.0),
mt::lt (compute_answer (), 43)));
});

The overloaded logical operators of the micro_test_plus::operators namespace are deprecated since 5.1.0, in favour of these functions.

The all_of function template provides a generic logical conjunction for any expression types. It constructs a detail::and_op logical conjunction object, which evaluates to true if all the operands are true. For more than two operands, the objects are nested from the left, (a and b) and c, and the expression formatter writes them as a single chain, (a and b and c).

All the operands are evaluated before the check, so, unlike the standard algorithm of the same name, the function does not stop at the first operand that is false.

The name is the same as that of std::all_of: after a using namespace std, an unqualified call with three or more operands of the same type selects the standard algorithm, so the function must be called as mt::all_of().

The any_of function template provides a generic logical disjunction for any expression types. It constructs a detail::or_op logical disjunction object, which evaluates to true if at least one of the operands is true; the disjunction is inclusive, so the result is also true when all the conditions are true. For more than two operands, the objects are nested from the left, and the expression formatter writes them as a single chain, (a or b or c).

All the operands are evaluated before the check, so the function does not stop at the first operand that is true; and, as for all_of(), it must be called as mt::any_of() after a using namespace std.

An object that evaluates to true if the operand is false.

The negate function template provides a generic logical negation for any expression type. It constructs a detail::not_op logical negator object, which evaluates to true if the operand is false; the template argument is named, since the class template argument deduction would copy an operand that is itself a not_op, instead of negating it.

It is the function form of the ! operator from the micro_test_plus::operators namespace.
