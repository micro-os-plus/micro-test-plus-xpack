 Reads the system clock.

Detailed Description

The unnamed namespace gives the helpers internal linkage, so that they are visible only in this translation unit, and cannot conflict with the names of the application or of the other source files of the framework. They are not declared in any header.

It contains read_clock(), which isolates the platform-specific access to the system clock.

void micro_os_plus::micro_test_plus::detail::anonymous_namespace{stopwatch.cpp}::read_clock ( timespec & ts)
noexcept

On Windows, the current time is captured via timespec_get() with TIME_UTC. On POSIX platforms with CLOCK_MONOTONIC defined, clock_gettime(CLOCK_MONOTONIC) is used to obtain a monotonic reading. On platforms where neither macro is defined, ts is left unchanged.
