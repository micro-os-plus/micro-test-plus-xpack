Detailed Description

A test case is created with test(), called on a suite, with a name and a callable, usually a lambda that receives the test case ([] (auto& t) { ... }), followed by any arguments for the callable. The test case runs immediately, within the call, and its checks are made on the test case received by the lambda (t.expect (...)).

Write one test case for each behaviour of the code under test; the report shows the result of each test case, so a failure points to the behaviour that broke.

A test case can contain other test cases, created with test() on the test case itself (t.test (...)); they are reported nested.

Example
namespace mt = micro_os_plus::micro_test_plus;
// In main(), after tr.add_top_suite():
ts.test ("Check various conditions", [] (auto& t) {
t.expect (mt::eq (compute_answer (), 42)) << "answer eq 42";
t.expect (mt::ne (compute_answer (), 43)) << "answer ne 43";
});

Test cases for several values

test_each(), called on a suite or on a test case, creates and runs a test case for each value of a range (a container, an array, a span, or a view), of a list written in place, or of a tuple, whose values may have different types. The callable receives the test case and the value, and a generic lambda is needed for a tuple. Each test case is named after the common name, followed by the value in parentheses, such as Sizes (16); a value that cannot be written, such as an application type without an operator<<, is replaced by its position, starting at 1, such as Records (#2).

namespace mt = micro_os_plus::micro_test_plus;
ts.test_each ("Sizes", std::vector<int>{ 1, 16, 512 },
[] (auto& t, int size) { t.expect (mt::gt (size, 0)); });
ts.test_each ("Limits", { 3, 4 },
[] (auto& t, int limit) { t.expect (mt::gt (limit, 2)); });
ts.test_each ("Types", std::tuple{ 42, 1.5, "text" },
[] (auto& t, const auto& value) {
t.expect (mt::eq (value, value));
});

With the TAP reporter, the first call is reported as:

ok 1 - Sizes (1) # { passed, 1 check }
ok 2 - Sizes (16) # { passed, 1 check }
ok 3 - Sizes (512) # { passed, 1 check }
