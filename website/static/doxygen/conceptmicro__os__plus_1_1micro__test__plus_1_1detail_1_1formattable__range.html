Detailed Description

Template Parameters
TThe type to be checked.

The formattable_range concept is satisfied when T can be iterated by a range-based for statement, with begin() and end() members (container_like) or functions (free_range), and:

  • is not an array, since the arrays are compared by address, and are written as addresses, as the pointers they decay to;
  • is not a string (see has_npos), which is written as text;
  • does not have elements of its own type, like std::filesystem::path, whose elements are paths, so that formatting it would recurse without end;
  • has elements that satisfy extension::printable, so that a range of elements that cannot be reported is rejected where it is compared, not where its elements are formatted.

The conditions are tested in this order, so the elements of a recursive range are not tested.
