Detailed Description

This header provides the declarations for the function comparator templates and logical operators used within the µTest++ framework. It defines the interfaces for the generic comparison functions, including equality, non-equality, greater than, less than, greater than or equal, and less than or equal, and the approximate comparison with an explicit tolerance (approx). Additionally, it declares logical combinators such as conjunction (all_of), disjunction (any_of), and negation (negate); their deprecated v5.0.1 names are declared in deprecated.h.

These comparators and logical operators enable expressive and type-safe test expectations and assertions. The C strings (char arrays, including the string literals, and char pointers) are compared by content, and so are the other arrays (e.g. byte buffers), element by element; the other pointers are compared by address. The operands are not copied: the temporaries are moved into the returned expressions, and the named operands of class type are referred to, so the expressions must be checked before the named operands are destroyed, as they are in expect (eq (a, b)). The logical combinators have descriptive names, since and, or, and not are alternative tokens and cannot be used as identifiers.

All definitions reside within the micro_os_plus::micro_test_plus namespace, ensuring clear separation from user code and minimising the risk of naming conflicts.

The header files are organised within the include/micro-os-plus/micro-test-plus folder to maintain a structured and modular codebase.

This file is intended solely for internal use within the framework and should not be included directly by user code.
