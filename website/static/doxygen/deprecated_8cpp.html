Detailed Description

This source file contains the non-inline definitions of the deprecated definitions declared in deprecated.h:

  • reflection::short_name(), which extracts the base file name from a fully qualified path, by delegating to utility::extract_file_name();
  • the constructor of detail::timestamp that reads the system clock, with detail::read_clock(), the same clock as detail::stopwatch.

All definitions reside within the micro_os_plus::micro_test_plus namespace.

This file must be included when building the µTest++ library.
