Detailed Description

The first parameter of suite::test() and test_case::test(). The constructors are not explicit, so a string literal, a const char*, or a std::string passed as the test case name converts implicitly; the default argument of the constructors is evaluated at the place of the conversion, which is the call to test() in the user code, so the location of the test case is captured without an additional argument (which could not follow the variadic arguments of test()).

The location is used to report a failure that is not associated with a check, such as an exception escaping the test case body.

The name is not copied. Since the test cases run immediately, within the call to test(), a temporary string passed as the argument, which lives until the end of the full expression, remains valid while the test case runs; a named test_case_name object must not outlive the string it was constructed from.

A std::string_view is not accepted, since it is not guaranteed to be null-terminated; pass std::string (sv) instead.

Since a conversion sequence may include only one user-defined conversion, an argument that converts to const char* or to std::string via a user-defined conversion operator must be converted explicitly.

A helper function that adds test cases on behalf of its caller can take a const test_case_name& parameter and pass it to test(), so that the reported location is that of the call to the helper, not that of the call to test() inside the helper.

Example
namespace mt = micro_os_plus::micro_test_plus;
void
check_answer (mt::suite& ts, const mt::test_case_name& name, int v)
{
ts.test (name, [v] (auto& t) { t.expect (mt::eq (v, 42)); });
}
