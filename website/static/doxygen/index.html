micro-test-plus

The µTest++ project is a C++20 testing framework for embedded systems, which also runs on the native platforms. The tests are ordinary C++ code, with no preprocessor macros, organised in test suites and test cases.

The results are written in the TAP (Test Anything Protocol) format by default, which the continuous integration systems and the TAP tools read. A human-readable format is also available, for reading the results on the console.

The command-line options select the format, how much is displayed (from nothing, with only the exit code, to every check), the colours, an output file, and the test cases to run.

Getting started

The applications include a single header, micro-os-plus/micro-test-plus.h. The header declares nothing unless the macro MICRO_OS_PLUS_MICRO_TEST_PLUS_ENABLED is defined, preferably in micro-os-plus/micro-test-plus-defines.h, for the application and for the library sources (see Configuration).

A complete test program has a runner, initialised with the command-line arguments, a top suite created in main() (optional, since the suites can be added to the runner instead), test cases with checks, and returns the exit code of the session:

#include <micro-os-plus/micro-test-plus.h>
namespace mt = micro_os_plus::micro_test_plus;
mt::runner tr;
int
main (int argc, char* argv[])
{
tr.initialise (argc, argv);
auto& ts = tr.add_top_suite ();
ts.test ("Check truth", [] (auto& t) {
t.expect (mt::eq (6 * 7, 42)) << "the answer is 42";
});
return tr.run_suites ();
}
