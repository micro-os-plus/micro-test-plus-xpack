Detailed Description

template<class Lhs_T, class Rhs_T>
struct micro_os_plus::micro_test_plus::detail::and_op< Lhs_T, Rhs_T >

Derived from binary_op, this struct combines two sub-expressions with a logical AND operation. It enables composition of complex assertions by combining multiple conditions into a single logical whole, with reporting that shows the combined result and individual operand outcomes.

The sub-expressions are not copied: the temporaries are moved into the comparator, and the named ones are referred to (see stored_operand_t).

Template Parameters
Lhs_TThe type of the stored left-hand sub-expression, either its type, or a const reference to it.
Rhs_TThe type of the stored right-hand sub-expression, either its type, or a const reference to it.
