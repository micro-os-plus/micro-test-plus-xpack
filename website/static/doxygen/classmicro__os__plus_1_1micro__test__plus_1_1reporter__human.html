Detailed Description

reporter_human provides a concrete implementation of the reporter abstract interface, formatting and presenting test results in a human-readable form. It accumulates output in an internal string buffer and writes it to the standard output stream, supporting colour-coded diagnostics (when the output is a terminal) and multiple verbosity levels.

The reporter is created by the runner, as selected by the --reporter command-line option. A different output format requires a new class derived from reporter, and an extension of the runner to create it.

All members and methods are defined within the micro_os_plus::micro_test_plus namespace, ensuring clear separation from user code and minimising the risk of naming conflicts.

subtestReference to the subtest.

With normal or verbose verbosity, this method summarises the outcome of the test case, with appropriate formatting and colour coding; for silent or quiet verbosity levels, no output is produced.

For passing test cases, a "✓ <name> - passed" line is shown with the number of checks; the buffered check results are written to stdout only with verbose verbosity. For failing test cases, the buffered check results are always shown (preceded, with normal verbosity, by the test case name), followed by a "✗ <name> - FAILED" line with the number of successful and failed checks. The buffered results are always written to the output file.

Finally, the streams are flushed and the buffer is cleared.
