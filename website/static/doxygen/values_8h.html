Detailed Description

This header provides the declarations for the value wrapper types used within the µTest++ framework: the op base struct, shared by all the framework expression types, the value_base common base, the compile-time integral_constant and floating_point_constant types, created by the literals, the run-time value<T> type, named by the to_* and _* aliases, and the named_bool type, created by the _b literal.

The wrappers carry the operands of the comparisons, so that the comparators can apply the type-specific rules (for example the precision of the floating point values) and the reporters can print the actual values.

All definitions reside within the micro_os_plus::micro_test_plus::detail namespace, since users name these types only through the literals and the aliases, never directly.

All header files are organised within the include/micro-os-plus/micro-test-plus folder to maintain a structured and modular codebase.

This file is intended for internal use within the framework and should not be included directly by user code.
