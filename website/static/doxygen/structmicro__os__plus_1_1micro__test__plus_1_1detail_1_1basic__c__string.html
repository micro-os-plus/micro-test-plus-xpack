Detailed Description

template<character Char_T>
struct micro_os_plus::micro_test_plus::detail::basic_c_string< Char_T >

The comparators convert the arrays (including the string literals) and the pointers of the character types to this type (see as_operand()), so that they are compared by content, as a reader of a test expects, and not by address. A null pointer is equal only to another null pointer (not to an empty string), and is less than any string.

The characters are not copied; the operand must outlive the comparison, which is always the case within a check.
