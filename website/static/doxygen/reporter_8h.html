Detailed Description

This header provides the declarations for the test reporting facilities used within the µTest++ framework. It defines the endl and indent() stream manipulators, and the abstract reporter base class, which accumulates output in a buffer, writes it to the console and to an optional output file, and dispatches the pass/fail results and the session, suite, and test case events to the concrete reporters (reporter_human and reporter_tap).

The formatting of the values and the comparison expressions is delegated to detail::expression_formatter.

The verbosity levels, and the other session options, are defined in runner-options.h. The manipulators and the reporter are defined in the micro_os_plus::micro_test_plus::detail namespace, since the reporters are internal to the framework.

The header files are organised within the include/micro-os-plus/micro-test-plus folder to maintain a structured and modular codebase.

This file is intended solely for internal use within the framework and should not be included directly by user code.
