Detailed Description

template<class T>
struct micro_os_plus::micro_test_plus::detail::value_base< T >
Template Parameters
TThe type of the stored value.

The value_base struct template stores the value in a private member, and provides an explicit operator T() conversion and a get() accessor, shared by integral_constant, value<T>, and the floating point specialisation of value<T>.

It declares the op_type marker, so that all derived types satisfy the extension::is_op concept without each struct needing to declare it.

It does not derive from the empty op struct: a type with an empty base and only floating point members, like value<float>, is a homogeneous floating point aggregate whose parameter passing with C++17 and later changed in GCC 10.1, and GCC emits a -Wpsabi note for each function passing or returning it by value, like approx(), on AArch64 and on 32-bit Arm with the hard-float ABI.
