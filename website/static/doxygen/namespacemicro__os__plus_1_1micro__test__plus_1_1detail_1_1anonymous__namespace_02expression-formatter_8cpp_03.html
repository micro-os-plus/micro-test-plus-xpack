void append_hex (std::string &buffer, char32_t code, std::string_view escape, std::size_t count)
 Appends an escape and a fixed number of hexadecimal digits.

Detailed Description

The unnamed namespace gives the helpers internal linkage, so that they are visible only in this translation unit, and cannot conflict with the names of the application or of the other source files of the framework. They are not declared in any header.

It contains append_hex(), which writes the hexadecimal escapes of the characters that cannot be printed as they are.
