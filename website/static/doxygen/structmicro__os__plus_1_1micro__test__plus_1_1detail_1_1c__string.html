Detailed Description

The comparators convert the char arrays (including the string literals) and the char pointers to this type (see as_operand()), so that they are compared by content, as a reader of a test expects, and not by address. A null pointer is equal only to another null pointer (not to an empty string), and is less than any string.

The characters are not copied; the operand must outlive the comparison, which is always the case within a check.
