Detailed Description

This header provides the declarations for the internal components of the µTest++ framework, encapsulated within the micro_os_plus::micro_test_plus::detail namespace. It defines the core mechanisms, helper structures, and utility templates that underpin the framework's value retrieval, comparator logic, operand preparation, and exception checking facilities.

All definitions reside within the micro_os_plus::micro_test_plus::detail namespace, ensuring clear separation from user code and minimising the risk of naming conflicts.

The header files are organised within the include/micro-os-plus/micro-test-plus folder to maintain a structured and modular codebase.

This file is intended solely for internal use within the framework and should not be included directly by user code.

◆ MICRO_OS_PLUS_MICRO_TEST_PLUS_PRI_SIZE

#define MICRO_OS_PLUS_MICRO_TEST_PLUS_PRI_SIZE   "zu"

Clang's format checker on Windows (the "ms_printf" archetype) rejects the standard z modifier, even though the UCRT printf() implementation supports it at run time, so the Microsoft-specific I modifier is used there instead ("Iu"); elsewhere it is "zu".

It is used in all the library formats that print size_t values, in the reporter output and in the trace messages alike, concatenated with the adjacent string literals, as the standard PRIu32 macros are (for example "%" MICRO_OS_PLUS_MICRO_TEST_PLUS_PRI_SIZE " checks").

The templates in the inline headers use it too; their string literals are concatenated when they are parsed, not when they are instantiated, so the macro is undefined at the end of micro-test-plus.h, after all the headers, to keep it out of the application code. The library sources include the individual headers, which keep it defined.
