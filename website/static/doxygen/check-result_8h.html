Detailed Description

This header provides the check_result class, the object returned by expect() and require(), together with the check_kind enumeration and the failure_info structure, passed to the reporter. The check result captures the result of one check and reports the outcome only when it is destroyed (i.e. at the semicolon following the expression statement), after the optional user message was appended via operator<<.

It also defines failed_requirement, the exception thrown to stop a test case after a failed require().

Both live in the detail namespace and are not part of the public API.

This file is intended solely for internal use within the framework and should not be included directly by user code.
