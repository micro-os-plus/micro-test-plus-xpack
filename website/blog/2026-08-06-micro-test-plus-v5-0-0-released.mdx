The [µTest++ Testing Framework](https://micro-os-plus.github.io/micro-test-plus-xpack/)
project is a C++ source code library that provides a lightweight testing framework specifically designed for embedded systems.

<CommonPrerequisites nodeVersion="18.0.0"/>

## Installation

The most straightforward method to incorporate the `@micro-os-plus/micro-test-plus`
package into a project is to declare it as a dependency using **xpm**.

<CodeBlock language="console"> {
`xpm install @micro-os-plus/micro-test-plus@${frontMatter.version} -verbose
`} </CodeBlock>

Comprehensive instructions are available in the [Install Guide](/docs/install/).

## Enhancements

- the configuration file is now `<micro-os-plus/micro-test-plus-defines.h>`
- to enable tracing, the new preprocessor macros are 
`MICRO_OS_PLUS_MICRO_TEST_PLUS_TRACE_ENABLED` and 
`MICRO_OS_PLUS_MICRO_TEST_PLUS_TRACE_CONSTRUCTORS_ENABLED`
