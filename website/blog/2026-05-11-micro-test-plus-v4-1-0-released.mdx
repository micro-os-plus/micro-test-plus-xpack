The [µTest++ Testing Framework](https://micro-os-plus.github.io/micro-test-plus-xpack/)
project is a C++ source code library that provides a lightweight testing framework specifically designed for embedded systems.

<CommonPrerequisites nodeVersion="18.0.0" />

## Installation

The most straightforward method to incorporate the `@micro-os-plus/micro-test-plus`
package into a project is to declare it as a dependency using **xpm**.

<CodeBlock language="console">
  {" "}
  {`xpm install @micro-os-plus/micro-test-plus@${frontMatter.version} -verbose
`}{" "}
</CodeBlock>

Comprehensive instructions are available in the [Install Guide](/docs/install/).

## Enhancements

- [[#31](https://github.com/micro-os-plus/micro-test-plus-xpack/issues/31)]:
  Move the top default suite name from the runner constructor to the
  `initialise()` functions, and also accept as default the program name.
- [[#27](https://github.com/micro-os-plus/micro-test-plus-xpack/issues/27)]:
  Split definitions from declarations.
- [[#28](https://github.com/micro-os-plus/micro-test-plus-xpack/issues/28)]:
  Reorganise inlines.
- [[#29](https://github.com/micro-os-plus/micro-test-plus-xpack/issues/29)]:
  Extract expression formatting code from reporter.
- [[#30](https://github.com/micro-os-plus/micro-test-plus-xpack/issues/30)]:
  Move internal classes to the `details` namespace.
