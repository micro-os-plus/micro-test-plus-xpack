## MDX

The pages are written in [MDX](https://mdxjs.com), a format that integrates
[JSX](https://react.dev/learn/writing-markup-with-jsx) with markdown.

The result is a static site, enhanced with JavaScript code specific to
[React](https://react.dev) components.

## Docusaurus

The tool used to generate the site is [Docusaurus](https://docusaurus.io),
a widely used open source project.
