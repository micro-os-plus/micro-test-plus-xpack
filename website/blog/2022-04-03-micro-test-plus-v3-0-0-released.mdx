## Install

The most convenient way to integrate the `@micro-os-plus/micro-test-plus`
package into a project is to add it as a dependency via **xpm**.

<CodeBlock language="console"> {
`xpm install @micro-os-plus/micro-test-plus@${frontMatter.version} --verbose
`} </CodeBlock>

However, like any source code library, this project can also be
integrated into another project in the traditional manner, either
by copying the relevant files into the target project or by
linking the entire project as a Git submodule.

Detailed instructions can be found in the [Integration Guide](/docs/install/).
