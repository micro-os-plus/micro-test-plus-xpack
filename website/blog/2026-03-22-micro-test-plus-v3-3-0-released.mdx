## Major changes

TAP stands for [Test Anything Protocol](https://testanything.org). It is a simple text-based interface between testing modules in a test harness, decoupling the reporting of errors from the presentation of the results.

The output is also relatively easy to read by humans; it looks like:

```tap
TAP version 14
# Subtest: Minimal
    # Subtest: Check truth
        ok 1 - true
        1..1
    ok 1 - Check truth # { test case passed, 1 check }
    1..1
ok 1 - Minimal # { test suite passed, 1 check in 1 test case, time: 0.007 ms }
1..1
# { total: 1 check passed, 0 failed, in 1 test case, 1 test suite, time: 0.030 ms }
```
