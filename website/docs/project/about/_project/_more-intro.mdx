µTest++ is a lightweight testing framework for C++20 projects. It is
designed primarily for embedded targets, where it runs on bare-metal
Cortex-M, Cortex-A, and RISC-V devices and on QEMU, but it is equally
suitable for native applications on Linux, macOS, and Windows.

Within µOS++, it is used to write the tests of the other packages, such
as `diag-trace` and `utils-lists`. It does not depend on any other
µOS++ package, so it can also be used in projects unrelated to µOS++.
