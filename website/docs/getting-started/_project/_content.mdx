## Overview



The **µTest++** project (_micro test plus plus_) is a C++ source code library that provides a testing framework with **a small memory footprint**, designed mainly for running unit tests on **embedded** platforms in a reproducible way.

<DetailsReproducibleOperations />

<EmbeddedBareMetal />

The open-source **µTest++** project is hosted on GitHub as
[micro-os-plus/micro-test-plus-xpack](https://github.com/micro-os-plus/micro-test-plus-xpack). The content is also published as [@micro-os-plus/micro-test-plus](https://www.npmjs.com/package/@micro-os-plus/micro-test-plus/) on the `npmjs.com` repository
and can be integrated into projects as an
[xpm](https://xpack.github.io/xpm/) dependency.
