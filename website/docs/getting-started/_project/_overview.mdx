## Overview

The **µTest++ Testing Framework** project (_micro test plus plus_) is a
**macro-free** C++ library offering a testing framework characterised by a
**minimal memory footprint**, primarily intended for executing unit tests on
**embedded** platforms in a reproducible manner. Test results are reported in
**[TAP](https://testanything.org) (Test Anything Protocol)** format, 
enabling straightforward integration
with standard TAP-aware tooling.
