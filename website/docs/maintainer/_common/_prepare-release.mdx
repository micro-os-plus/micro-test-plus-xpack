### Prepare the release


- switch to the `xpack-development` branch
- if there are changes, **commit** all changes into the `xpack-development` branch

- update `CHANGELOG.md`, add a line like _**\* v3.2.0 published on npmjs.com**_

- `npm run pack`; check the list of packaged files, possibly
