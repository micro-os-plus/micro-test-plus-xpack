### Start the local web server

Execute the npm script **clear** followed by **start** in the website sub-project,
or execute the following within the project folder:

```sh
npm --prefix ~/Work/micro-os-plus/micro-test-plus-xpack.git/website run clear
npm --prefix ~/Work/micro-os-plus/micro-test-plus-xpack.git/website run start
```

The local copy of the site is then available at
[http://localhost:3000/micro-test-plus-xpack/](http://localhost:3000/micro-test-plus-xpack/), and its
pages are updated when the source files change.
