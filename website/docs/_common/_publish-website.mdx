### Publish the website

The website deployment is performed automatically when pushing to the
`website` branch, utilising a dedicated workflow in
[GitHub Actions](https://github.com/micro-os-plus/micro-test-plus-xpack/actions/workflows/publish-github-pages.yml).

- Open https://micro-os-plus.github.io/micro-test-plus-xpack/docs/maintainer/#publish-the-website in a separate window
- **Stop** the local web server
- Switch to the `webpreview` branch
- **Rebase** the `xpack-development` branch onto the `webpreview` branch
- **Push** the `webpreview` branch to GitHub
  :::info
  At this point, an automated GitHub Action will generate and publish 
  the [preview website](https://micro-os-plus.github.io/micro-test-plus-xpack-webpreview/).
  :::
- Switch to the `website` branch
- run the `npm install` command, to ensure `package-lock.json` is up to date
- **Rebase** the `xpack-development` branch onto the `website` branch
- **Push** the `website` branch to GitHub
  :::info
  At this point, an automated forwarding GitHub Action will trigger 
  a GitHub Action in the separate project to generate and publish 
  the [website]https://micro-os-plus.github.io/micro-test-plus-xpack/.
  :::
- Check out the `xpack-development` branch
- **Wait** for the publication to complete 
- check [GitHub Pages](https://github.com/micro-os-plus/micro-test-plus-xpack/actions/workflows/publish-github-pages.yml) workflow
- **Refresh** the web page
- The new release blog post is available
at https://micro-os-plus.github.io/micro-test-plus-xpack/blog/
- Record the post URL, as it must be used to update the release page
and the X/Twitter announcement

The `website` branch may be subsequently updated, provided the
version in `package.json` remains unchanged.

Verify the result at https://micro-os-plus.github.io/micro-test-plus-xpack/.
