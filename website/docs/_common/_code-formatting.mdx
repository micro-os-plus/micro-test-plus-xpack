## Code formatting

For formatting style, the project employs a
[.clang-format](https://clang.llvm.org/docs/ClangFormat.html)
configuration file based on the GNU style, in the `maintenance/config` folder.

The source files are formatted with the `clang-format` xpm action,
which runs `clang-format` with that configuration on the C and C++ files of
the project:

```sh
xpm run clang-format -C ~/Work/micro-os-plus/micro-test-plus-xpack.git
```

Similarly, the `cmake-format` and `jsonc-format` actions format the CMake and
the JSONC files.

:::info

The `clang-format` program is installed by `xpm install`, as a development
dependency of the project, in the `xpacks/.bin` folder.

:::

:::tip

Always **reformat** the modified source files before committing them.
Enabling format-on-save in your editor makes this automatic.

:::
