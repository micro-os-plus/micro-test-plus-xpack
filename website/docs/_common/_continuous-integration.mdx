The library is subject to continuous integration (CI) testing with every
push using [GitHub Actions](https://github.com/micro-os-plus/micro-test-plus-xpack/actions).
The tests run on Ubuntu, macOS, and Windows.

Testing is conducted on both 32-bit and 64-bit bare-metal platforms,
including a selection of Arm Cortex-M, Cortex-A and RISC-V, running
using QEMU.

The native tests run with the GCC and LLVM/clang compilers.

A workflow that runs the tests on all the supported platforms and
configurations can be triggered manually.
