### Manual tests

There are predefined xpm actions available to manually execute various
tests on the local development machine.

Start with a clean-up (not needed after the initial `git clone`):

```sh
npm --prefix ~/Work/micro-os-plus/micro-test-plus-xpack.git/tests install
npm --prefix ~/Work/micro-os-plus/micro-test-plus-xpack.git/tests run deep-clean
npm --prefix ~/Work/micro-os-plus/micro-test-plus-xpack.git/tests install
```

:::tip

During the initial execution, the installation step may require a considerable
amount of time, as it needs to download the toolchain archives, which
can be relatively large, up to several hundred megabytes.

:::

#### Native system compiler tests

To execute the tests with the system compiler (usually not available on Windows):

```sh
xpm run install -C ~/Work/micro-os-plus/micro-test-plus-xpack.git/tests
xpm run test -C ~/Work/micro-os-plus/micro-test-plus-xpack.git/tests
```

#### More native and QEMU tests

To execute a selection of tests with the latest versions of toolchains:

```sh
xpm run install-selected -C ~/Work/micro-os-plus/micro-test-plus-xpack.git/tests
xpm run test-selected -C ~/Work/micro-os-plus/micro-test-plus-xpack.git/tests
```

To execute all tests with the latest versions of toolchains:

```sh
xpm run install-latest -C ~/Work/micro-os-plus/micro-test-plus-xpack.git/tests
xpm run test-latest -C ~/Work/micro-os-plus/micro-test-plus-xpack.git/tests
```

To execute all tests with all toolchain versions:

```sh
xpm run install-all -C ~/Work/micro-os-plus/micro-test-plus-xpack.git/tests
xpm run test-all -C ~/Work/micro-os-plus/micro-test-plus-xpack.git/tests
```

#### Physical boards tests

To build the physical boards binaries with the latest versions of toolchains:

```sh
xpm run install-boards -C ~/Work/micro-os-plus/micro-test-plus-xpack.git/tests
xpm run build-boards -C ~/Work/micro-os-plus/micro-test-plus-xpack.git/tests
```

Running the tests on a physical board requires the board to be connected and
powered up. To execute the tests for a specific board configuration with the
latest versions of toolchains:

```sh
xpm run install-nucleo-f411re-cmake-gcc -C ~/Work/micro-os-plus/micro-test-plus-xpack.git/tests
xpm run test-nucleo-f411re-cmake-gcc -C ~/Work/micro-os-plus/micro-test-plus-xpack.git/tests
```

### Clean-ups

Executing all tests may require several gigabytes of space.

To clean up the tests folder, use:

```sh
npm --prefix ~/Work/micro-os-plus/micro-test-plus-xpack.git/tests install
npm --prefix ~/Work/micro-os-plus/micro-test-plus-xpack.git/tests run deep-clean
npm --prefix ~/Work/micro-os-plus/micro-test-plus-xpack.git/tests install
```

A considerable amount of space may also be used by the toolchains.
When no longer required, they can be removed with `xpm uninstall`.
