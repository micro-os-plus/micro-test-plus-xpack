## Build & Integration Information

This project is implemented in C++. Tests are also expected to be written in
C++, although the code under test may be written in standard C.

The source code has been compiled natively using **GCC** and **LLVM/clang**,
and cross-compiled for embedded **Arm** and **RISC-V** targets, with no
warnings.

For execution on **embedded platforms**, the test framework requires only
minimal system support: the ability to write to an output stream. Any
environment providing this capability is suitable; for standalone tests,
the most common approach is **Arm semihosting**.

Pre-configured **CMake** and **Meson** build files are provided to simplify
integration into user projects, as described below. For alternative build
systems, refer to the sections that follow.

### Include Folders

The following folder should be passed to the compiler during the
build process:

- `include`

The primary header file to include in user projects is:

```cpp
#include "micro-os-plus/micro-test-plus.h"
```

:::caution
No other header file should be included explicitly by the application.
:::

### Source Files

All source files in the `src` folder should be incorporated into user
projects. The files are:

- `deferred-reporter.cpp`
- `reflection.cpp`
- `reporter-human.cpp`
- `reporter-tap.cpp`
- `reporter.cpp`
- `runner-totals.cpp`
- `runner.cpp`
- `timings.cpp`
- `utility.cpp`

### Preprocessor Definitions

The build can be configured using the following preprocessor definitions:

- `MICRO_OS_PLUS_TRACE` - to include and enable to implement the trace calls
- `MICRO_OS_PLUS_MICRO_TEST_PLUS_TRACE_ENABLED` – to enable tracing messages specific to µTest++
- `MICRO_OS_PLUS_MICRO_TEST_PLUS_TRACE_CONSTRUCTORS_ENABLED` – to enable tracing messages for object constructors and destructors

The recommended way to pass the `MICRO_OS_PLUS_TRACE` macro and 
garantee it is seen in the whole project is via the 
compiler command line options, as `-DMICRO_OS_PLUS_TRACE`.

The recommended way to define the `micro-test-plus` specific macros is to use a 
separate header file,`micro-os-plus/micro-test-plus-defines.h`, and define the 
macros there (uncomment the desired lines).

```c title="micro-os-plus/micro-test-plus-defines.h"
#ifndef MICRO_OS_PLUS_MICRO_TEST_PLUS_DEFINES_H_
#define MICRO_OS_PLUS_MICRO_TEST_PLUS_DEFINES_H_

// µTest++, a lightweight testing framework for embedded platforms.
#if !defined(MICRO_OS_PLUS_MICRO_TEST_PLUS_ENABLED)
#define MICRO_OS_PLUS_MICRO_TEST_PLUS_ENABLED
#endif // MICRO_OS_PLUS_MICRO_TEST_PLUS_ENABLED

// Display trace messages in the µTest++ testing framework when TRACE is
// enabled.
// #if !defined(MICRO_OS_PLUS_MICRO_TEST_PLUS_TRACE_ENABLED)
// #define MICRO_OS_PLUS_MICRO_TEST_PLUS_TRACE_ENABLED
// #endif // MICRO_OS_PLUS_MICRO_TEST_PLUS_TRACE_ENABLED

// Display trace messages in constructors and destructors in the µTest++
// testing framework when TRACE is enabled.
// #if !defined(MICRO_OS_PLUS_MICRO_TEST_PLUS_TRACE_CONSTRUCTORS_ENABLED)
// #define MICRO_OS_PLUS_MICRO_TEST_PLUS_TRACE_CONSTRUCTORS_ENABLED
// #endif // MICRO_OS_PLUS_MICRO_TEST_PLUS_TRACE_CONSTRUCTORS_ENABLED

// ----------------------------------------------------------------------------

#endif // MICRO_OS_PLUS_MICRO_TEST_PLUS_DEFINES_H_

// ----------------------------------------------------------------------------
```

For xCDL enabled projects, this file is automatically generated.

The `cdlSettings` to enable them are:

```jsonc title="xcdl-project.jsonc"
    "cdlConfigurations": {
      //
      "<name>": {
        ...
        "cdlSettings": {
          ...
          "micro-os-plus.micro-test-plus.trace": true,
          "micro-os-plus.micro-test-plus.trace.constructors": true
        }
      },
      ...
    }
```

### Compiler Options

The following options **must** be supplied to the compiler and linker:

- `-std=c++20` or later for C++ source files

### Dependencies

This library has a single external dependency, used only when compiling
in Debug mode:

- [µOS++ Tracing Infrastructure](https://micro-os-plus.github.io/diag-trace-xpack/)
