## Build & Integration Information

This project is implemented in C++, and it is expected that tests will also be written in C++, although the code under test may be written in standard C.

The source code has been compiled natively using **GCC** and **LLVM/clang**, and cross-compiled for embedded **Arm** and **RISC-V** targets, ensuring that it is free from warnings.

For execution on **embedded platforms**, the test framework requires only minimal system support, such as the ability to write to an output stream. Any environment providing this capability is suitable; however, for standalone tests, the most common approach is to employ **Arm semihosting**.

To simplify integration into user projects, pre-configured **CMake** and **meson** build files are provided (see below).

For alternative build systems, please consult the information provided below.

### Include Folders

The following folder should be specified to the compiler during the build process:

- `include`

The primary header file to include in user projects is:

```cpp
#include <micro-os-plus/micro-test-plus.h>
```

### Source Files

The following source files should be incorporated into user projects:

- `src/micro-test-plus.cpp`
- `src/test-reporter.cpp`
- `src/test-runner.cpp`
- `src/test-suite.cpp`

### Preprocessor Definitions

The build can be configured using the following preprocessor definitions:

- `MICRO_OS_PLUS_INCLUDE_CONFIG_H` – to include `<micro-os-plus/config.h>`
- `MICRO_OS_PLUS_TRACE` – to enable trace calls
- `MICRO_OS_PLUS_TRACE_MICRO_TEST_PLUS` – to activate specific tracing messages

### Compiler Options

The following options must be supplied to the compiler and linker:

- `-std=c++20` or later for C++ source files

### Dependencies

This library does not have any external dependencies.
