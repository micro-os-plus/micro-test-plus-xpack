The most convenient method for integrating the **µTest++ Testing Framework** into a project is to **add it as a dependency** using **xpm**.

Alternatively, as with any source code library, this project may be incorporated into another project in the traditional manner, either by **copying the relevant files** into the target project or by **linking** the entire project as a **Git submodule**.

## Automated Installation

In addition to the source files, this project includes a `package.json` file containing metadata that identifies it as an **xpm**/**npm** package. This enables direct installation from GitHub or from the [npmjs.com](https://www.npmjs.com) registry as [`@micro-os-plus/micro-test-plus`](https://www.npmjs.com/package/@micro-os-plus/micro-test-plus).
