# The µTest++ Testing Framework

A source code library with µTest++, a lightweight testing framework for embedded platforms.

## Project documentation

For information on how to use this project, please refer to the
[project website](https://micro-os-plus.github.io/micro-test-plus-xpack/).

## Project source

The source code of the current release is available on
GitHub as [micro-os-plus/micro-test-plus-xpack](https://github.com/micro-os-plus/micro-test-plus-xpack),
the [v5.0.0](https://github.com/micro-os-plus/micro-test-plus-xpack/tree/v5.0.0) tree.
