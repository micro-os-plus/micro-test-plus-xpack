# stm32cubemx/README

## STM32CubeMX

This content of this folder is generated by STM32CubeMX.

The configuration is stored in `stm32cubemx.ioc` and the content can
be updated at any time.

## Customisations

### `Core/src/main.c`

The `main()` function must be renamed
`micro_os_plus_startup_initialise_hardware_hook` via a preprocessor,
to inititalise the hardware and to avoid clashing with µOS++ similar function.

```c
/* Private user code ---------------------------------------------------------*/
/* USER CODE BEGIN 0 */

// Trick to avoid clashing with the µOS++ specific main().
// Do not call it directly, since it configures again the clocks.
// Copy relevant calls to os_startup_initialize_hardware().
int micro_os_plus_startup_initialise_hardware_hook (void);
#define main micro_os_plus_startup_initialise_hardware_hook

/* USER CODE END 0 */
```

The infinite loop must be commented out:

```c
  /* Infinite loop */
  /* USER CODE BEGIN WHILE */
  // while (1)
  //  {
      /* USER CODE END WHILE */

      /* USER CODE BEGIN 3 */
  //  }
  return 0;
  /* USER CODE END 3 */

```

## CMake

## `startup_stm32f411xe.s`

The assembly file `startup_stm32f411xe.s` must **not** be included in the build,
the functionality being provided by the portable `startup-xpack` package.

## `vectors-stm32f411xe.c`

The file was added to replace the STM assemply file.

## Memory map

The memory map is copied from `stm32f411xe_FLASH.ld` into
`device/linker-scripts/mem.ld`
