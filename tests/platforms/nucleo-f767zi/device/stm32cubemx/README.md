# stm32cubemx/README

## STM32CubeMX

This content of this folder is generated by STM32CubeMX.

The configuration is stored in `stm32cubemx.ioc` and the content can
be updated at any time.

## Customisations

### `Core/src/main.c`

The `main()` function must be renamed (for example to `cmsis_main()`)
via a preprocessor , to avoid clashing with µOS++ similar function. 

```c
/* Private user code ---------------------------------------------------------*/
/* USER CODE BEGIN 0 */

// Trick to avoid clashing with the µOS++ specific main().
// Do not call it directly, since it configures again the clocks.
// Copy relevant calls to os_startup_initialize_hardware().
int cubemx_main(void);
#define main cubemx_main

// ----------------------------------------------------------------------------

void
micro_os_plus_startup_initialise_hardware (void);

void
micro_os_plus_startup_initialise_hardware (void)
{
  // ...
}

/* USER CODE END 0 */
```

The initialisations in `main()` must be  manually copied to
`micro_os_plus_startup_initialise_hardware ()`.

## `startup_stm32f767xx.s`

The assembly file `startup_stm32f767xx.s` must **not** be included in the build,
the functionality being provided by the portable `startup-xpack` package.

## `vectors-stm32f767xx.c`

The file was added to replace the STM assemply file.

## Memory map

The memory map is copied from `STM32F767xx_FLASH.ld` into
`device/linker-scripts/mem.ld`
